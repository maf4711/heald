  <action>
Create `Sources/heald/Collectors/` directory and `CPUCollector.swift`.

Import `Darwin`, `ServiceLifecycle`, `OSLog`. The collector owns all Mach pointer state (`cpuInfo`, `prevCpuInfo`, `numCPUsU`, etc.) inside its `run()` method — these are local variables, not stored properties, avoiding Swift 6 Sendable issues.

**Critical implementation details (from research):**

1. **Tick-delta pattern:** Call `host_processor_info(mach_host_self(), PROCESSOR_CPU_LOAD_INFO, &numCPUsU, &cpuInfo, &numCpuInfo)`. For each core `i`, compute:
   - `inUse = (USER_now - USER_prev) + (SYSTEM_now - SYSTEM_prev) + (NICE_now - NICE_prev)`
   - `total = inUse + (IDLE_now - IDLE_prev)`
   - `usage = total > 0 ? Double(inUse) / Double(total) : 0.0`
   - Array index: `base = Int(CPU_STATE_MAX) * i`

2. **Memory leak prevention:** After delta calculation, `vm_deallocate(mach_task_self_, vm_address_t(bitPattern: prevCpuInfo!), vm_size_t(numPrevCpuInfo * UInt32(MemoryLayout<integer_t>.size)))`. Then set `prevCpuInfo = cpuInfo`.

3. **First sample handling:** When `prevCpuInfo` is nil, just store current as baseline and publish CPUSnapshot.zero. This avoids the misleading startup values pitfall.

4. **ps output locale note:** CPU values from Mach APIs are ticks (integers), no locale issue here (that's only for `ps` output parsing in ProcessCollector).

5. **Polling loop:** `repeat { collect; await store.updateCPU(snapshot); try await Task.sleep(for: .seconds(5)) } while !shutdown`

6. **Logging:** `Logger.collector.debug("CPU: overall \(snapshot.overall, format: .fixed(precision: 1))% cores=\(snapshot.perCore.count)")` on each cycle.

Create `Sources/heald/Collectors/RAMCollector.swift`.

Import `Darwin`, `ServiceLifecycle`, `OSLog`.

**Critical implementation details (from research):**

1. **RAM via host_statistics64:**
   ```swift
   var stats = vm_statistics64()
   var count = UInt32(MemoryLayout<vm_statistics64_data_t>.size / MemoryLayout<integer_t>.size)
   let result: kern_return_t = withUnsafeMutablePointer(to: &stats) {
       $0.withMemoryRebound(to: integer_t.self, capacity: 1) {
           host_statistics64(mach_host_self(), HOST_VM_INFO64, $0, &count)
       }
   }
   ```
   Multiply all page counts by `Double(vm_page_size)` to get bytes.

2. **Used calculation (matching Activity Monitor):**
   `used = active + inactive + speculative + wired + compressed - purgeable - external`

3. **Swap via sysctlbyname:**
   ```swift
   var swap = xsw_usage()
   var swapSize = MemoryLayout<xsw_usage>.size
   sysctlbyname("vm.swapusage", &swap, &swapSize, nil, 0)
   ```
   Fields: `swap.xsu_used`, `swap.xsu_total` (both in bytes).

4. **Memory pressure:**
   ```swift
   var pressure: Int = 0
   var pressureSize = MemoryLayout<Int>.size
   sysctlbyname("kern.memorystatus_vm_pressure_level", &pressure, &pressureSize, nil, 0)
   ```
   Values: 1=normal, 2=warning, 4=critical.

5. **Swap spike detection flow:**
   After `await store.updateRAM(snapshot)`, call `let spike = await store.detectSwapSpike(current: snapshot)`. If non-nil, log:
   `Logger.collector.warning("Swap spike: +\(spike.deltaBytes / 1_048_576, format: .fixed(precision: 1))MB, pressure=\(spike.pressureLevel), suspect=\(spike.suspectProcess?.name ?? "unknown")")`

6. **Polling loop:** Same pattern as CPUCollector — `withGracefulShutdownHandler`, `Task.sleep(for: .seconds(5))`.
