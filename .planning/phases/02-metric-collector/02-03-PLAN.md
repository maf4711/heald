**Multi-interval polling strategy:**
Use a single 5-second base loop. Track cycle count. Execute sub-collectors based on cycle:
- Every cycle (5s): Disk I/O
- Every 12th cycle (60s): Disk space
- Every 60th cycle (300s): SMART health

```swift
struct DiskCollector: Service {
    let store: MetricsStore

    func run() async throws {
        var shutdown = false
        var cycle = 0
        var prevIO: [String: DiskIOCounters] = [:]  // BSD name -> previous counters

        try await withGracefulShutdownHandler {
            repeat {
                var volumes: [VolumeSpaceInfo] = []
                var ioDeltas: [DiskIODelta] = []
                var smartInfos: [SMARTInfo] = []

                // Disk I/O — every 5s
                let (deltas, newCounters) = readDiskIO(previous: prevIO)
                ioDeltas = deltas
                prevIO = newCounters

                // Disk space — every 60s (cycle % 12 == 0)
                if cycle % 12 == 0 {
                    volumes = readDiskSpace()
                }

                // SMART — every 300s (cycle % 60 == 0)
                if cycle % 60 == 0 {
                    smartInfos = readSMART()
                }

                let snapshot = DiskSnapshot(volumes: volumes, io: ioDeltas, smart: smartInfos, timestamp: Date())
                await store.updateDisk(snapshot)
                cycle += 1
                try await Task.sleep(for: .seconds(5))
            } while !shutdown
        } onGracefulShutdown: {
            shutdown = true
        }
    }
}
```

**Disk space (MON-03)** — `readDiskSpace()`:
- Use `FileManager.default.mountedVolumeURLs(includingResourceValuesForKeys: [.volumeNameKey], options: .skipHiddenVolumes)`
- For each URL, call `statfs(url.path, &stat)` — use `statfs`, NOT `statvfs` (statvfs returns incorrect f_bsize on macOS, 256x too large)
- Compute: `totalBytes = Int64(stat.f_blocks) * Int64(stat.f_bsize)`, `freeBytes = Int64(stat.f_bfree) * Int64(stat.f_bsize)`
- Get volume name from `url.lastPathComponent` or `url.resourceValues(forKeys: [.volumeNameKey]).volumeName`
- Note: `stat.f_mntonname` is a tuple of CChar — convert with `withUnsafePointer(to: stat.f_mntonname) { String(cString: UnsafeRawPointer($0).assumingMemoryBound(to: CChar.self)) }`

**Disk I/O (MON-04)** — `readDiskIO(previous:)`:
- Get physical disk BSD names. Use a simple heuristic: enumerate `disk0`, `disk1`, etc. up to `disk9`. For each, try `IOServiceGetMatchingService(kIOMainPortDefault, IOBSDNameMatching(kIOMainPortDefault, 0, bsdName))`.
- For each matched service, traverse parents (max 10 depth) until finding `IOBlockStorageDriver`: `while IOObjectConformsTo(current, "IOBlockStorageDriver") == 0 { ... }`
- Use `kIOMainPortDefault` (NOT deprecated `kIOMasterPortDefault`)
- Read `"Statistics"` dictionary: `"Bytes (Read)"` and `"Bytes (Write)"` as Int64 cumulative counters
- Compute delta from previous counters. First cycle: store baseline, return empty deltas.
- **IMPORTANT:** Release all IOKit objects with `IOObjectRelease()` to prevent handle leaks

**IOKit IORegistryEntryCreateCFProperties usage:**
```swift
var propsRef: Unmanaged<CFMutableDictionary>?
let kr = IORegistryEntryCreateCFProperties(current, &propsRef, kCFAllocatorDefault, 0)
guard kr == KERN_SUCCESS, let props = propsRef?.takeRetainedValue() as? [String: Any] else { ... }
```

**SMART health (MON-08)** — `readSMART()`:
- For each physical disk BSD name, run `Process()` with `/usr/sbin/diskutil info -plist <bsdName>`
- Parse output via `PropertyListSerialization.propertyList(from:format:)` as `[String: Any]`
- Extract `SMARTStatus` key (String: "Verified", "Failing", or nil for unsupported)
- Extract from `SMARTDeviceSpecificKeysMayVaryNotGuaranteed` dict: `AVAILABLE_SPARE` (Int?), `PERCENTAGE_USED` (Int?), `TEMPERATURE` (Int?), `POWER_ON_HOURS_0` (Int?)
- Handle `nil` / "Not Supported" gracefully — some drives (USB) don't support SMART

**Logging:**
- `Logger.collector.debug("Disk space: \(volumes.count) volumes")` on space collection
- `Logger.collector.debug("Disk I/O: \(ioDeltas.count) drives")` on I/O collection
- `Logger.collector.info("SMART: \(smartInfos.count) drives checked")` on SMART collection (less frequent, info level)
- `Logger.collector.warning("SMART failing: \(info.bsdName)")` if any drive reports "Failing"

**Process list collection (MON-05, MON-06):**

Run `ps -Aceo pid,pcpu,rss,uid,comm -r` via Foundation `Process`:
```swift
let task = Process()
task.executableURL = URL(fileURLWithPath: "/bin/ps")
task.arguments = ["-Aceo", "pid,pcpu,rss,uid,comm", "-r"]
let pipe = Pipe()
task.standardOutput = pipe
task.standardError = Pipe()  // suppress stderr
try task.run()
task.waitUntilExit()
```

**Parsing details:**
- Skip the first line (header: "PID  %CPU   RSS   UID COMM")
- Split each line by whitespace: `line.split(separator: " ", maxSplits: 4, omittingEmptySubsequences: true)`
  - parts[0] = PID (Int32)
  - parts[1] = %CPU (Double) — **CRITICAL: replace "," with "." before parsing** for locale safety (German locale uses comma decimal separator in ps output, confirmed in research)
  - parts[2] = RSS in kilobytes (Int64)
  - parts[3] = UID (Int)
  - parts[4] = COMM (String) — may contain spaces, hence maxSplits: 4
- Convert RSS to bytes: `rss * 1024`
- Set `isSystem = uid < 500`
- Skip lines that fail to parse (guard with continue)

**Ranking (MON-06):**
- `byCPU`: Take first 25 entries from parsed list — `ps -r` already sorts by %CPU descending
- `byRAM`: Sort all entries by `ramBytes` descending, take first 25

**Polling loop:** Same `withGracefulShutdownHandler` pattern, 5-second interval.

**Logging:**
- `Logger.collector.debug("Processes: \(entries.count) total, top CPU=\(byCPU.first?.name ?? "none") \(byCPU.first?.cpuPercent ?? 0)%")`

**Error handling:**
- If `ps` fails (non-zero exit code), log at `.error` level and publish `.empty` snapshot
- If output is empty, log at `.warning` level and publish `.empty` snapshot
